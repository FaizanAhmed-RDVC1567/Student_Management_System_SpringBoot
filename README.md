# Student_Management_System_SpringBoot
A small project that shows off the basic concepts behind Spring and Spring Boot, 
by using a simple student management system.

<h1>About Project</h1>
This project is built to understand the core concepts of Spring Boot:  

<ol>
    <li> REST APIs </li>
    <li> Dependency Injection </li>
    <li> JPA Data Access </li>
</ol>
